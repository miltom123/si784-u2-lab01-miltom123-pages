La solución MyMath aplica el ciclo de pruebas unitarias a una biblioteca de raíces cuadradas. Se documentan la implementación, el comportamiento ante entradas inválidas y las automatizaciones de documentación, cobertura y distribución NuGet.

Ejemplo de uso

using Math.Lib;

Rooter rooter = new();
Console.WriteLine(rooter.SquareRoot(16));

El resultado aproxima 4 con una tolerancia relativa de 0,1 %.

Contenido

  • Desarrollo y explicación de las pruebas.
  • Automatización de publicaciones.
  • Referencia de clases y métodos.
  • Reporte HTML de cobertura.

Reproducir la entrega

Desde la raíz del repositorio, con .NET 8 y PowerShell 7:

pwsh ./scripts/Build-Site.ps1

El sitio completo se genera en artifacts/site/index.html. Incluye la API obtenida de los comentarios XML y la cobertura calculada sobre la ejecución de las pruebas.
