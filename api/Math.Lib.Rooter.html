Examples

Remarks

Se aplica x(n+1) = (x(n) + input/x(n))/2. La media se calcula en dos mitades para evitar desbordamiento con valores grandes. El valor inicial es al menos uno para admitir entradas muy pequeñas.

Exceptions

ArgumentOutOfRangeException

La entrada es cero, negativa, NaN o infinita. Incluye InvalidInputMessage.
